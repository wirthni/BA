\section{Summary and Outlook}

The jet-induced diffusion wake was successfully measured using the correlation of soft hadrons with a dijet/dihadron trigger pair in ALICE RUN 3 0-10\% Pb--Pb data at $\sqrt{s_{NN}} = 5.36\bunit{TeV}$. The analysis was done without compensating for detector acceptance or tracking efficiency effects.

The analysis results using a correlated dijet pair as trigger revealed anomalies as systematic errors at $|\eta| = 0.3$, especially for lower jet trigger $p_T$ thresholds. Apart from that the diffusion wake signal could be identified among all trigger variants, $(40,20)\bunit{GeV/c}, (30,15)\bunit{GeV/c}, (20,10)\bunit{GeV/c}$.

The result of the $(40,20)\bunit{GeV/c}$ trigger variant was compared to another ALICE analysis that uses 0-30\% Pb--Pb data. This 0-30\% data includes one Pb--Pb dataset that is also used in the 0-10\% analysis. The 0-10\% result is very similar to the 0-30\% result although the 0-30\% result has, on average,smaller absolute values than ALICE 0-10\% result has. In the $0 \leq p_T \leq 2 \bunit{GeV/c}$ soft hadron bin the correlation difference for 0-10\% is globally higher, indicating a systematic error in large/small gap events separately. Only the 0-30\% signal is asymmetric in pseudorapidity as expected. It also shows a smaller residual signal for higher soft hadron bins as expected. The 0-10\% result for the $(40,20)\bunit{GeV/c}$ trigger variant was also compared to a CoLBT-hydro prediction. The prediction provides data for the soft hadron bins $1 \leq p_T \leq 2 \bunit{GeV/c}$ and $2 \leq p_T \leq 4 \bunit{GeV/c}$. The $1 \leq p_T \leq 2 \bunit{GeV/c}$ prediction fits the 0-10\% result well for $\eta > 0$, but not for $\eta < 0$. There, the systematic error shifts the diffusion wake signal out of the prediction's bounds. The $2 \leq p_T \leq 4 \bunit{GeV/c}$ prediction fits the ALICE 0-10\% data well.

The analysis results using a correlated dihadron pair as trigger is not subject to anomalies and reveals less noisy results across all trigger variants, $(30,15)\bunit{GeV/c}, (20,15)\bunit{GeV/c}, (15,10)\bunit{GeV/c}, (15,8)\bunit{GeV/c}$. The $(15,8)\bunit{GeV/c}$ trigger variant was added afterwards because the $(15,10)\bunit{GeV/c}$ variant showed promising results. The diffusion wake signal is clearest in the $(15,8)\bunit{GeV/c}$ trigger variant for soft hadrons with transverse momenta $0 \leq p_T \leq 2 \bunit{GeV/c}$.





The comparison between the dijet and dihadron analysis in both cases, the original flow $v_2$ and the magnified flow $v_2'$ has brought interesting results. The signal opposing bias with the original $v_2$ is bigger for a dijet trigger than for a dihadron trigger
